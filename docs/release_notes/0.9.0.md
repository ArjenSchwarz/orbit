# Orbit & Apsis v0.9.0

Initial public release.

## What's Included

### Orbit - AI Coding Agent Orchestrator

Orbit automates running AI coding agents through multi-phase implementation tasks. It handles the full lifecycle: reading task files, invoking agents per phase, retrying on errors, and saving transcripts.

**Multi-agent support** - Works with Claude Code, OpenAI Codex, AWS Kiro, GitHub Copilot, and OpenCode. Each agent has its own error classifier for intelligent retry behavior (rate limits, connection errors, session expiry). Claude Code's 5-hour usage limit is detected and waited out automatically.

**Phase-based orchestration** - Reads rune task files and runs agents through phases sequentially. Sessions persist across phases and survive crashes. Pre/post prompts wrap the phase loop for setup and review. Shell command hooks run before and after agent execution.

**Multi-variant comparison** - Run N parallel implementations with different agents, models, or guidance. AI-powered comparison generates HTML/Markdown reports with per-file analysis, recommendations, and cross-variant learnings. Consolidation merges good ideas from non-chosen variants. Finalization adopts the chosen variant via fast-forward merge.

**Monitoring** - `orbit status` shows live progress with commits, git state, and task completion. `orbit serve` provides a web dashboard with run history and transcript viewing. Centralized JSON Lines logging to `~/.orbit/logs/`.

**Configuration** - Layered config (CLI > env vars > project `.orbit.yaml` > home `~/.orbit.yaml` > defaults). Agent aliases support per-variant model selection. `orbit init` generates a starter config.

### Apsis - Session Transcript Viewer

Apsis converts AI agent transcripts into readable Markdown or HTML.

**Transcript conversion** - Reads all 5 agent formats (Claude JSONL, Codex JSONL, Copilot JSONL, Kiro CLI SQLite/JSON, Kiro IDE JSON). Auto-detects format. `apsis latest` shows the most recent session. Follow mode (`-F`) streams updates in real time.

**Session discovery** - `apsis -l` lists sessions across all agents for the current project. Resolution by session ID or direct file path.

**Web interface** - `apsis serve` starts a local session browser with filtering, search, dark mode, and auto-refresh.

### Build Infrastructure

- Multi-platform release binaries via GitHub Actions (linux/windows/darwin x amd64/arm64)
- Build metadata (version, commit, build time) injected via ldflags
- CI workflow for automated testing and linting

## Installation

```bash
go install github.com/arjenschwarz/orbit/cmd/orbit@v0.9.0
go install github.com/arjenschwarz/orbit/cmd/apsis@v0.9.0
```

Or download pre-built binaries from the [GitHub release](https://github.com/arjenschwarz/orbit/releases/tag/v0.9.0).

## Prerequisites

- Go 1.25.4+
- [rune](https://github.com/arjenschwarz/rune) CLI for task management
- At least one supported AI agent CLI installed and authenticated

## Known Limitations

- Go 1.25.5 has known standard library vulnerabilities (crypto/tls, html/template, net/url). Upgrade to Go 1.25.9+ when available.
- `RunOptions.Timeout` field exists but is unused by all agents; use context timeouts instead.
